# Contributing to Relazio Plugin SDK

Grazie per l'interesse nel contribuire all'SDK Relazio! 🎉

## Come Contribuire

### Segnalazione Bug

Se trovi un bug, apri una [GitHub Issue](https://github.com/relazio/plugin-sdk/issues) includendo:

- Descrizione del problema
- Passi per riprodurre
- Comportamento atteso vs effettivo
- Versione SDK e Node.js
- Codice di esempio (se possibile)

### Richiesta Features

Per suggerire nuove funzionalità:

1. Controlla se esiste già una issue simile
2. Apri una nuova issue con label `enhancement`
3. Descrivi il caso d'uso e il beneficio

### Pull Requests

1. Fork il repository
2. Crea un branch per la feature: `git checkout -b feature/nome-feature`
3. Implementa i cambiamenti
4. Aggiungi test se applicabile
5. Verifica che il codice compili: `npm run build`
6. Commit: `git commit -m "feat: descrizione"`
7. Push: `git push origin feature/nome-feature`
8. Apri una Pull Request

### Convenzioni Codice

- Usa TypeScript strict mode
- Segui lo stile esistente
- Commenta codice complesso
- Mantieni backward compatibility

### Testing

```bash
npm test
```

## Domande?

Apri una [Discussion](https://github.com/relazio/plugin-sdk/discussions) o contattaci via email.

Grazie per il supporto! 🚀
